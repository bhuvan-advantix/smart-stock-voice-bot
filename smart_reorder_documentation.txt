
SMART REORDER – FULL DOCUMENTATION

Author: Developer A
Use Case: Ops – Inventory Automation

---------------------------------------------------
OBJECTIVE
---------------------------------------------------
Automate the detection of low-stock SKUs, generate reorder suggestions, and send daily email + CSV outputs — reducing manual tracking effort.

---------------------------------------------------
SYSTEM OVERVIEW
---------------------------------------------------
- n8n – Orchestration engine (ETL + notifications)
- Postgres (Docker) – Central database (Products, Inventory, Sales, Runs)
- Gmail – Sends reorder alerts and error notifications
- Files – Incoming CSV data + generated reorder CSVs

---------------------------------------------------
SETUP INSTRUCTIONS (STEP BY STEP)
---------------------------------------------------

1) INSTALL & RUN POSTGRES + N8N
--------------------------------
- Install Docker Desktop.
- Create a project folder:
  mkdir smart-reorder && cd smart-reorder
- Create docker-compose.yml:

version: "3.1"
services:
  postgres:
    image: postgres:15
    restart: always
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: smartreorder
    volumes:
      - ./db-data:/var/lib/postgresql/data
    ports:
      - "5432:5432"

  n8n:
    image: n8nio/n8n
    restart: always
    ports:
      - "5678:5678"
    environment:
      - DB_TYPE=postgresdb
      - DB_POSTGRESDB_HOST=postgres
      - DB_POSTGRESDB_PORT=5432
      - DB_POSTGRESDB_DATABASE=smartreorder
      - DB_POSTGRESDB_USER=postgres
      - DB_POSTGRESDB_PASSWORD=postgres
    volumes:
      - ./n8n-data:/home/node/.n8n

- Run containers:
  docker compose up -d
- Access n8n UI: http://localhost:5678

2) SETUP POSTGRES SCHEMA
-------------------------
Connect to Postgres (psql or pgAdmin) and run:

CREATE TABLE IF NOT EXISTS products (
  sku TEXT PRIMARY KEY,
  name TEXT,
  lead_time_days INT,
  reorder_point_days INT,
  target_stock_days INT,
  safety_stock INT,
  created_at TIMESTAMP DEFAULT now()
);

CREATE TABLE IF NOT EXISTS inventory (
  sku TEXT PRIMARY KEY REFERENCES products(sku),
  on_hand INT,
  last_counted_at TIMESTAMP
);

CREATE TABLE IF NOT EXISTS runs (
  id SERIAL PRIMARY KEY,
  run_at TIMESTAMP DEFAULT now(),
  status TEXT,
  message TEXT
);

3) PREPARE FOLDER STRUCTURE
-----------------------------
smart-reorder/
├── data/
│   └── incoming/            (Place daily inventory.csv here)
├── reorder_exports/         (Workflow writes daily CSV here)
├── docker-compose.yml

4) CONFIGURE N8N WORKFLOW
-------------------------
Import Smart reorder.json into n8n.

Node Naming Convention:
- Daily Trigger – runs every morning at 01:00 AM
- Manual Trigger – for manual runs
- Load Inventory CSV – reads incoming CSV
- Parse & Clean Inventory Data – prepares JSON
- Upsert Products Table – sync products table
- Upsert Inventory Table – sync inventory table
- Fetch Low-Stock SKUs – SQL query for low-stock items
- Format Email Data – build HTML email
- Send Reorder Alert Email – Gmail notification
- Prepare CSV Output → Convert to CSV → Save CSV – write CSV to disk
- Error Trigger + Send Error Email – error notifications

5) DAILY RUN FLOW
-----------------
- Scheduler triggers workflow
- Inventory CSV read & parsed
- DB tables upserted
- SQL fetches low-stock SKUs
- Email + CSV generated
- Error email sent if any node fails

6) TESTING
----------
- Place inventory.csv into /data/incoming
- In n8n, click Execute workflow
- Check Gmail inbox for alert email
- Verify /data/reorder_exports/ for CSV output
- Optionally run:
  SELECT * FROM inventory;

7) TROUBLESHOOTING
------------------
- Check DB tables: psql -U postgres -d smartreorder -c "\dt"
- View n8n execution logs
- Restart: docker compose restart
- Fix missing SKUs: add to CSV and rerun

---------------------------------------------------
OUTPUTS

Email: Reorder Alert with SKU, On Hand, Safety Stock, Recommended Qty
CSV: reorder_suggestions_YYYY-MM-DD.csv in /data/reorder_exports
